# Midnight Ledger

Nocturnal personal finance for night owls and freelancers. Raat ki shifts, tips, freelance, aur chhote kharche — ek hi phone screen pe.

## Run

```bash
npm install
npm run dev
```

## What's inside

- **Tonight** — live clock, tonight's balance, sparkline vs last night, shift pills, After dark list (Dusk / Midnight / Small hours), quick add
- **Ledger** — search, income/expense filter, tap a row to edit the note or category
- **Insights** — seven nights, where the money went, heaviest cost
- **Settings** — your name, ₹ / $ / €, restore the sample night

Entries stay in this browser. Nothing is sent anywhere.
